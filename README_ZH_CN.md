# OpenLauncher

> [!IMPORTANT]
> 这是 [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2) 的**非官方修改版本**。  
> 本 Fork 移除了账户区域限制，现在你可以在任何地区使用离线账户而无需关联 Microsoft 账户。

**OpenLauncher** 是 Zalith Launcher 2 的一个分支——一款面向 **Android 设备** 的 [Minecraft: Java Edition](https://www.minecraft.net/) 启动器。项目使用 [PojavLauncher](https://github.com/PojavLauncherTeam/PojavLauncher/tree/v3_openjdk/app_pojavlauncher/src/main/jni) 作为启动核心，采用 **Jetpack Compose** 与 **Material Design 3** 构建现代化 UI 体验。
