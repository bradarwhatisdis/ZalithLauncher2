# OpenLauncher

> [!IMPORTANT]
> 這是 [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2) 的**非官方修改版本**。  
> 本 Fork 移除了帳戶區域限制，現在你可以在任何地區使用離線帳戶而無需關聯 Microsoft 帳戶。

**OpenLauncher** 是 Zalith Launcher 2 的一個分支——一款面向 **Android 裝置** 的 [Minecraft: Java Edition](https://www.minecraft.net/) 啟動器。專案使用 [PojavLauncher](https://github.com/PojavLauncherTeam/PojavLauncher/tree/v3_openjdk/app_pojavlauncher/src/main/jni) 作為啟動核心，採用 **Jetpack Compose** 與 **Material Design 3** 構建現代化 UI 體驗。
